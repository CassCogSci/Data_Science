# Data_Science

README Data Science & Machine Learning Project
Project Overview
This project explores the application of statistical learning and machine learning techniques for predictive modelling and data-driven analysis. The work was completed as part of the Data Science, Prediction, and Forecasting MSc Cognitive Science course. The project combines principles from statistical modelling, resampling methods, regression, classification, and model evaluation to investigate relationships within complex datasets and assess predictive performance.
The project draws conceptually on key themes from modern statistical learning, including:
supervised learning,
regression and classification,
bias–variance trade-offs,
cross-validation and resampling,
model selection and regularisation,
prediction versus explanation,
and interpretable versus algorithmic modelling approaches.

OBJECTIVES
The primary aims of this project were to:
preprocess and clean real-world data,
explore patterns and relationships using visualisation,
implement predictive machine learning models,
compare model performance using resampling techniques,
evaluate generalisation performance on unseen data,
and interpret the strengths and limitations of different modelling approaches.

METHODS USED
The project incorporates several statistical and machine learning methods, including:
Data Preparation
handling missing values,
feature selection,
scaling and transformation,
train/test splitting,
exploratory data analysis (EDA).
Missing-data handling decisions were informed by contemporary recommendations favouring principled approaches over ad hoc deletion or single imputation methods.

MACHINE LEARNING TECHNIQUES
Depending on the analysis stage, models may include:
Linear Regression
Logistic Regression
Ridge Regression
Lasso Regression
Decision Trees
Random Forests
Support Vector Machines
K-Nearest Neighbours
Gradient Boosting
Neural Networks
These approaches align with the statistical learning framework described in An Introduction to Statistical Learning and the course materials.

MODEL EVALUATION
Model performance was evaluated using resampling methods such as:
validation-set approaches,
k-fold cross-validation,
bootstrap estimation,
and held-out test data.
Cross-validation was used to estimate prediction error and reduce overfitting risk.
Typical evaluation metrics included:
RMSE (Root Mean Squared Error),
MAE (Mean Absolute Error),
R² score,
classification accuracy,
precision,
recall,
and F1-score.

VISUALISATION
Visualisations were created to support exploratory analysis and communicate findings clearly. The project follows evidence-based recommendations for effective visual communication, including:
minimising misleading graphical encodings,
using colour-blind-safe palettes,
reducing unnecessary visual complexity,

KEY CONCEPTS
The project engages with an important distinction in modern data science between:
explanatory statistical models focused on inference and interpretation,
and algorithmic machine learning models focused on predictive performance.
This distinction informed model selection and interpretation throughout the project.
