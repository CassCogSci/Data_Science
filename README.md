# Data Science & Machine Learning Project

## Overview

This repository contains a data science and machine learning project completed as part of the *Data Science, Prediction, and Forecasting* module in the MSc Cognitive Science programme.

The project explores statistical learning and predictive modelling techniques using Python-based machine learning workflows. The analysis focuses on preprocessing, exploratory data analysis, model development, evaluation, and interpretation of predictive performance across multiple statistical and machine learning approaches.

---

# Project Objectives

The primary objectives of this project were to:

- preprocess and clean real-world data,
- perform exploratory data analysis (EDA),
- develop predictive machine learning models,
- compare model performance using resampling techniques,
- evaluate model generalisation,
- and interpret findings within a statistical learning framework.

---

# Methods

## Data Preparation

The preprocessing pipeline included:

- handling missing data,
- feature engineering,
- train/test splitting,
- scaling and normalisation,
- and exploratory visualisation.

---

## Machine Learning Models

The project explores multiple statistical and machine learning approaches, including:

- Linear Regression
- Logistic Regression
- Ridge Regression
- Lasso Regression
- Decision Trees
- Random Forests
- K-Nearest Neighbours
- Support Vector Machines
- Gradient Boosting
- Neural Networks

---

# Model Evaluation

Model performance was assessed using:

- train/test evaluation,
- k-fold cross-validation,
- bootstrap and resampling methods,
- and comparative performance metrics.

Evaluation metrics included:

- RMSE
- MAE
- R² score
- Accuracy
- Precision
- Recall
- F1-score
